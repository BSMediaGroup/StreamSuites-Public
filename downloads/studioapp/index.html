System requirements

Windows-native baseline

  • Windows 10 build 19041 or later
  • 64-bit Windows installation
  • Compatible display and Windows Graphics Capture support
  • No Visual Studio or .NET SDK required by the self-contained installer
  • Free storage greater than the published installer size, with additional headroom for installation and managed updates
  • Separate free storage for recordings, replay media, and temporary production files when those workflows are used

The exact installer size is hydrated from the validated release manifest above. Capture behavior varies by device, display topology, driver, and Windows configuration; no unsupported RAM, CPU, GPU, fixed disk-space, or vendor minimum is claimed.

Questions and support

Before you install.

Does StudioApp replace Browser Studio?

No. StudioApp is the Windows-native production surface; Browser Studio remains a separate browser experience.

Where is the installer hosted?

Only on the canonical StreamSuites update host. Public validates metadata and issues a controlled same-origin redirect after access checks.

Is capture automatic?

No. Display and audio capture require explicit operator action and are never started merely by launching StudioApp or opening a room.

Where can I get help?

Review the StreamSuites documentation or visit Public support.
