Implemented in development

OBS-native ownership

The plugin uses supported OBS module, frontend, dock, source, and Browser Source seams while OBS retains scene, mixer, composition, encoding, recording, and output ownership.

Architecture boundaries

Integration without duplicating the studio.

Runtime/Auth remains authoritative

Accounts, sessions, roles, permissions, rooms, invitations, tokens, credentials, destinations, automation, shared state, and canonical system authority stay in StreamSuites Runtime/Auth.

OBS retains its media pipeline

OBS owns capture surfaces, scenes, sources, its audio mixer, compositing, encoding, recording, and streaming output. The plugin does not become a media engine.

StudioApp stays separate

The OBS plugin does not replace StudioApp and does not duplicate StudioApp’s supervised native media engine.

No bundled OBS distribution

This project is a plugin/client. It is not an OBS fork and does not vendor or redistribute OBS as a competing application.

Not presented as complete

Important development limits remain.

Native media decoding, automatic scene layout, provider device control, production chat, alerts, overlays, automation controls, output orchestration, and a second provider path are not presented as available. This page makes no promise about public release timing or supported OBS versions.

Planned distribution

Public package approval is still pending.

When a public artifact is authorized, this area can present verified package, signature, hash, compatibility, installation, and licensing details. It contains no hidden or inactive artifact URL today.
