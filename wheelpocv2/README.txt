StreamSuites Wheel Detail POC v2

Focus of this revision:
- Rebuilt high-calibre wheel hardware, rim, pointer, hub, slice gradients, and lighting.
- Rotated wheel labels 90 degrees from POC v1 into a radial orientation.
- Aggregated repeated entrant records into one unique row/slice per entrant.
- Added a dedicated Entries column and probability visualization.
- Replaced the brief winner flash with a persistent celebratory winner presentation.
- Added finite canvas confetti and firework bursts, winner lighting, trophy treatment, and Continue / Spin again actions.
- Preserved the v1 shell and control-console concept for implementation inspiration.

Open index.html in a browser. Add ?winner=1 to open directly in the winner state.
This is a front-end proof of concept only and does not write Runtime/backend state.
