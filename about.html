Architecture with boundaries

One authority. Separate media paths.

Runtime/Auth is the canonical source for accounts, sessions, roles, permissions, rooms, invitations, credentials, destinations, alerts, automation, shared state, exports, and versioning.

It coordinates the suite, but it does not carry Browser Studio, StudioApp, or OBS media. Each production surface keeps its own appropriate media architecture and lifecycle.

Browser Direct browser media Windows Native engine media OBS OBS-owned media
