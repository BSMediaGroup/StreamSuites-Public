Operational boundary

Private WPF orchestration utility for the repository’s version, build, test, installer, publishing, and verification scripts. It contains no media engine and is excluded from end-user StudioApp installers and payloads.

StudioApp diagnostics

Add the app’s product metadata source, system compatibility source, OS, process architecture, .NET runtime, Engine status/protocol, Runtime/Auth status/origin, and relevant logs from its Copy Diagnostics action.

Alerts Client diagnostics

Add binary and file versions, local profile, configured public registry source, refresh time and freshness, and any nonsecret last error from its About surface.

Admin diagnostics

The public Desktop Admin and Dashboard cards provide shareable compatibility posture. Privileged readiness, credentials, internal deployment evidence, and operator-only registry data are intentionally not exposed here.
